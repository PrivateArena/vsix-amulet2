This is a redesign of vsix-amulet using https://github.com/Avhatar/pi-vscode-extension-avr https://github.com/Printaga/PiLot https://github.com/gnassro/phi https://github.com/quincycs/pi-qcode https://github.com/kaiwood/vscode-tauren fork instead of clean room re-implementing closed source Pendant.

What we want is a good foundation to build upon, then we expand and adjust to match the power of Pendant while skipping the parts that we don't need.

In this session, we try to study about these forks and decide which one to use as a base for our redesign.

The critical requirements are:

- Up to date, we want to fork active development project
- Codebase is clean, easy to understand, high quality, well-structured
- Good documentation
- Good license, we want to fork active development project
